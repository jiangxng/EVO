# Economic Context

Purpose: provide minimal shared semantic primitives below allocation/cost/valuation without reducing enterprise business meaning to generic fields.

Frozen boundary:
- BusinessData/EconomicOccurrence remains canonical business evidence.
- Measurement = value + unit + semantic role.
- BasisEvidence is canonical only when explicitly supplied/accepted as business evidence.
- RateObservation belongs to a pinned/versioned dataset and has an explicit semantic role.

Do not turn `foreignAmount`, `quantity`, `amount` or one generic `exchangeRate` into universal core truth.
