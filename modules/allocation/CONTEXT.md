# Allocation Context

Frozen distinction:

`Allocation Fact / Instruction / Constraint`
vs
`Allocation Interpretation Result`
vs
`Residual Position Projection`.

Legacy Asloop manual matching proved that the selected source constraint can be canonical business input while split allocation edges remain deterministic runtime results.

Automatic selection is governed by versioned eligibility, dimensions, ordering, partial-allocation, negative-state and precision/residual policies.

This module must remain domain-neutral: receivable settlement, inventory-layer consumption, order fulfillment and production allocation can share the substrate without losing their domain semantics.
