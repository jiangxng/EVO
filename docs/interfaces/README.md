# Interface Contracts

Cross-module interfaces are documented here.

Every material interface document must state:

- Purpose
- Owner
- Callers
- Input
- Output
- Preconditions
- Postconditions
- Invariants
- Transaction boundary
- Ordering guarantee
- Idempotency
- Consistency
- Error contract
- Versioning
- Performance expectation
- Security expectation
- Examples

Implementation classes are not interfaces merely because they have TypeScript methods.

Initial interface documents will be added as M1–M3 create real module contracts.
