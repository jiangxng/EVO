# EVO v0.9.2 Build Fix

Fixes TypeScript/Kysely build failures observed during Docker validation.

- JSON database columns now explicitly accept structured JSON values for insert/update.
- Database-default timestamps are typed as generated/optional on insert.
- decimal.js imports use the package named export compatible with the NodeNext TypeScript configuration.
- Retains the v0.9.1 strict optional-property fixes.

This release is a build-fix candidate; Docker runtime validation remains required on the target environment.
