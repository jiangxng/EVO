# EVO v1.0.0-alpha.1

Status: Architecture and semantic reference-flow alpha.

Highlights:

- first-class LLM Context Determinism contract
- canonical PHILOSOPHY / CONCEPTS / INVARIANTS / PUBLIC API docs
- context.manifest.json
- Item definition foundation
- Capability / Flow / Metric / SOP foundations
- explicit FlowTrace and BusinessObjectLink projection
- sales order carries explicit item identity
- reference inventory receipt now comes from `production.completed`
- sales shipment explicitly references order/item/warehouse and reduces pending shipment
- Cost engine consumes production completion + sales shipment semantics
- Dashboard exposes CostResult and FlowTrace
- ReplayRun separates before_snapshot from SHA-256 before_digest and records validation status

Known boundary: deterministic valuation posting from CostResult to Inventory Value/COGS is not yet implemented. It is intentionally not faked in this alpha.
