# Architecture Decision Records

ADR states:

- PROPOSED
- ACCEPTED
- SUPERSEDED
- REJECTED

Accepted history is not rewritten. A later change supersedes an old ADR with a new ADR.

Template sections:

1. Context
2. Decision
3. Alternatives
4. Consequences
5. Interface impact
6. Data impact
7. Compatibility
8. Migration
9. Rollback / roll-forward
10. Performance impact
11. References
